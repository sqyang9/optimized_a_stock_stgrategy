# A股科技成长股趋势策略 V2.0 - 优化说明

## 概述

本次优化基于诊断书的建议，对策略系统进行了全面升级，主要改进以下几个核心问题：

1. **缺乏择时机制** → 新增大盘择时模块
2. **止盈止损过于单一** → 增加时间止损、优化追踪止损
3. **板块效应利用不足** → 新增板块共振检测
4. **可视化维度不足** → 合并可视化模块、增加基准对比和水下分析

---

## 一、新增模块

### 1. 大盘择时模块 (`market_timer.py`)

**核心功能：**
- 基于沪深300指数的均线系统判断市场环境
- 牛市条件：价格 > MA20 > MA60
- 熊市条件：价格 < MA20 < MA60
- 震荡市：其他情况

**风控规则：**
- 熊市可禁止开仓（可配置）
- 指数单日跌幅超2%，暂停次日开仓
- 高波动环境自动限制仓位

**配置项（`config.py` - `MarketTimingConfig`）：**
```python
enabled: bool = True              # 是否启用
index_code: str = "000300"        # 基准指数
ma_short: int = 20                # 短期均线
ma_long: int = 60                 # 长期均线
allow_entry_in_bear: bool = False # 熊市是否允许开仓
range_max_position: float = 0.5   # 震荡市最大仓位
bear_max_position: float = 0.3    # 熊市最大仓位
index_drop_threshold: float = -0.02  # 指数跌幅预警
```

### 2. 板块共振检测（`signal_generator.py`）

**核心逻辑：**
- 检查同板块是否有多只股票同时触发信号
- 有共振的信号加分（默认+1分）
- 孤立信号降低仓位（默认50%）

**配置项（`config.py` - `SectorResonanceConfig`）：**
```python
enabled: bool = True              # 是否启用
min_sector_signals: int = 2       # 最少同板块信号数
resonance_bonus_score: int = 1    # 共振加分
isolated_signal_position_ratio: float = 0.5  # 孤立信号仓位折扣
```

## 二、止盈止损优化

### 1. 时间止损（新增）

**问题：** 原策略没有时间维度的出场机制，导致"僵尸仓位"长期占用资金。

**解决方案：**
- 持仓超过N天（默认5天）且未脱离成本区（盈利<1%），强制平仓
- 避免在纠结行情中浪费时间和资金

**配置项（`config.py` - `ExitConfig`）：**
```python
time_stop_enabled: bool = True
time_stop_days: int = 5
time_stop_profit_threshold: float = 0.01
```

### 2. 追踪止损优化

**原参数 → 新参数：**
- 初始止损ATR倍数：2.5 → 2.0（更紧）
- 追踪启动ATR：3.0 → 2.5（更早启动）
- 追踪ATR倍数：2.0 → 1.5（更紧跟踪）
- 收紧启动ATR：5.0 → 4.0

### 3. 分批止盈优化

**原参数 → 新参数：**
- TP1触发：3.0ATR → 2.5ATR（更早止盈）
- TP1卖出比例：30% → 50%（锁定更多利润）
- TP1后止损：1.0ATR → 0.5ATR（更紧保护）

## 三、仓位管理优化

### 1. 单票仓位调整
- 最大仓位：20% → 15%（降低集中风险）
- 板块仓位：40% → 35%

|---------|---------|---------|

## 五、使用方法

### 基本用法
```bash
python main.py --start 2024-01-01 --end 2024-12-31 --data ./data/daily
```

### 完整参数
```bash
python main.py \
    --start 2024-01-01 \
    --end 2024-12-31 \
    --data ./data/daily \
    --capital 1000000 \
    --simple \           # 简单报告模式
    --no-timing \        # 禁用大盘择时
    --no-resonance       # 禁用板块共振
```

## 七、预期效果

根据优化方向，预期可以实现：

1. **降低回撤**：大盘择时 + 时间止损可有效减少熊市亏损
2. **提高胜率**：板块共振过滤可筛选出更强信号
3. **锁定利润**：更早止盈 + 更紧追踪可减少利润回吐
4. **清晰归因**：增强可视化可帮助理解策略表现来源
